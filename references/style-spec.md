# 风格规格 · 军构美学

「军构美学」= 苏联构成主义（Constructivism）的几何语言 + 1930s 军事宣传画的印刷质感。

判定一张图是否合格，看下面七项是否同时成立。缺任何一项就退化成"红色军事题材插画"。

## ⚠️ 头号红线：禁止旭日旗语言

**任何从单一点向外扩散的放射状线条，都判定为失败。**

理由：红白放射 = 日本旭日旗，是二战轴心国军旗符号。军事题材里出现这个构图，轻则被举报，重则被当右翼符号处理。不管配色多"苏联"，这一条能直接让作品不可用。

必须做到的替换关系：

| ❌ 禁用 | ✅ 改用 |
|--------|--------|
| sunburst / radiating rays | 平行斜线束（hatch lines，全部同向平行） |
| sun / 日轮 | 无。背景不放太阳 |
| 从主体背后炸开的扇形光芒 | 大块斜切色带（diagonal slab / wedge） |
| 圆形放射徽章 | 阶梯几何、矩形色块、楔形 |
| rays emanating from a single point | 斜楔形分割画面（红楔形是构成主义正统） |

prompt 层面的硬性禁令段（每次生成都要带上，见 `prompt-templates.md` 的「反旭日禁令段」）：

```
no sunburst, no radiating rays, no rays from a single point, no fan of light,
no sun, no circular emblem, no badge, no rising-sun motif, no radial composition
```

自检口径：**画面里最显眼的扩散形结构不能是扇形/放射状**。如果是，就不合格。

## 1. 调色板（严格限定五色）

| 角色 | 色值 | 用途 |
|------|------|------|
| 纸底 | `#EFE5D2` 暖米白 | 背景主体色，占画面最大面积 |
| 朱红 | `#D22B1E` | 斜楔形、装备主色、强调块 |
| 墨黑 | `#16130F` | 轮廓线、剪影、大色块 |
| 赭金 | `#C79131` | 金属受光面、平行线束、点睛矩形 |
| 钴蓝 | `#3E6E8C` | 点睛：海面、天空、机械阴影面，用量不超过 10% |

规则：

- 平涂无渐变，同一块面里只允许一个颜色
- 颜色靠**色块并置**产生层次，不靠明暗过渡
- 赭金只用来提亮金属和做平行线束，不要大面积铺
- **背景大面积用米白 + 墨黑，朱红在背景里以楔形/斜带出现**，避免形成"红白大面积分割"的旗子联想

## 2. 线条

- 粗黑墨线勾勒主体轮廓，笔触偏钢笔速写，允许略有抖动
- 轮廓线不是均匀描边：主体关键结构加粗，细节处收细
- 背景辅助线用**同向平行的细黑线或赭金线**（hatching），**不是**从一点发散的射线

## 3. 几何语言

- **斜切色块**：1–2 条粗大的斜带/楔形把画面切开，构成主义的核心动作
- **阶梯几何**：阶梯、梯田、层叠台阶，沿画面下缘或侧边排布
- **城市工业剪影**：烟囱、塔吊、水塔、屋顶天际线，纯黑剪影压在纸底上（苏联宣传画最经典的背景层）
- **平行斜线束**：一组同向平行的细线作节奏纹理
- **几何山形**：尖锐三角形的层叠山峦，黑/红/赭金分层（仅在题材需要自然背景时用）
- **透视网格地面**：向消失点收敛的黑红米白方格面板
- **悬浮色块**：一两块纯色矩形/方形作为视觉锚点

## 4. 印刷质感

- 胶印/丝网印网点（halftone）在色块边缘可见
- 纸纹颗粒贯穿全图
- 套色轻微错位（misregistration），红黑边界有 1–2px 的错位
- 做旧：磨损斑、划痕、边缘泛黄

**注意**：做旧不能盖过可读性。纸底过脏会让画面从"复古"变成"脏"。

## 5. 主体

- 军事装备为主：战机、坦克、军舰、直升机、火箭、雷达、防空阵地
- 主体占画面主导（通常 60% 以上），构图上偏重、大仰角或强透视
- 人物（地勤、机组）用剪影或简化色块，人数少、手势明确
- 人物**通常不画五官**，这是风格的一部分，不是缺陷

## 6. 禁止项

- **放射状线条、扇形光芒、太阳/日轮**（见开头红线专章）
- 任何文字、标语、编号、字母
- 渐变、阴影、体积光、反射高光、写实纹理
- 装饰性印章、角标、出品标记
- 边框、画框
- 照片的原始水印（会被 AI"翻译"成乱码字符，必须在 prompt 里禁止）

## 7. 与参考族的区别

容易混的四种"看起来差不多但不是"：

| 错误类型 | 表现 |
|----------|------|
| 泛苏联风 | 配色更艳、加入大量渐变和写实金属反射 |
| 泛军事写实 | 追求真实质感，只有构图借了构成主义 |
| 美式复古海报 | 出现胶片褪色棕黄、圆形 badge 徽章、军衔领章 |
| **旭日旗化** | 背景出现扇形放射/日轮，无论配色多苏联都算失败 |
