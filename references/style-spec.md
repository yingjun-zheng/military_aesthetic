# 风格规格 · 军构美学

「军构美学」= 苏联构成主义（Constructivism）的几何语言 + 1930s 军事宣传画的印刷质感。

判定一张图是否合格，看下面七项是否同时成立。缺任何一项就退化成"红色军事题材插画"。

## 0. 装备识别度优先（2026-11-21 用户七图校准，优先级最高，压过本文件其他章节）

用户给了七张参考图（M1 坦克群 / J-35 特写 / 歼-15 甲板群 / 直升机 / T-72 开火 / 055 驱逐舰 / 数码迷彩装甲车），统一规律：

**装备层（保真）**
- 原涂装/迷彩颜色照搬：数码迷彩就是绿黄像素、海灰就是浅蓝灰、沙漠迷彩就是沙黄——**不许替换成海报色**
- 编号逐位复刻（106、3506、FK322 实测模型直接渲染可靠）、红星机徽、鲨鱼涂鸦、武器构型全保留
- 渲染方式：精细扁平矢量插画 + 几何切面明暗（色块拼接代替渐变光影），细节多但不写实、不抽象

**背景层（重构）**
- 大块几何切面：斜三角、楔形、放射状平面（非旗色下放射允许）
- 调色板：红、黑、赭金、米白 + 至多一个场景色（海蓝/夜绿）
- 地面场景极简化：甲板标线、马路、海浪全部扁平几何图形

**优先级关系**：本节压过第 1 节（五色调色板）和第 7 节（高调三色）——那两节的调色板**只约束背景**；装备主体永远保留原配色。第 7 节仅在用户明确要求"装备也海报化配色"时使用。

## ⚠️ 头号红线：禁止旭日旗构图（2026-11-21 修订口径）

**红/白日轮 + 放射光芒**的构图判定为失败，一票否决。

理由：红白放射 = 日本旭日旗，是二战轴心国军旗符号。军事题材里出现这个构图，轻则被举报，重则被当右翼符号处理。

| ❌ 禁用 | ✅ 允许 |
|--------|--------|
| 红色或白色日轮 + 从日轮放射的光芒 | 黑/金/蓝/米白的放射楔形、斜切光线、光束扇面（无中心日轮） |
| 红白大面积放射分割（旗子联想） | 红楔形斜切分割（构成主义正统） |
| 圆形放射徽章 | 几何矩形色块、楔形 |
| **任何太阳/月亮/圆形天体（含黑圆，2026-11-21 用户拍板）** | 背景留白，什么都不放 |

自检口径：**触线的是"日轮+放射"的组合与红白旗配色，不是放射本身**。画面里最显眼的结构如果是红日轮带光芒，不合格；蓝色海面上方黑/金色的放射平面，合格。

## 1. 调色板（严格限定五色）

| 角色 | 色值 | 用途 |
|------|------|------|
| 纸底 | `#EFE5D2` 暖米白 | 背景主体色，占画面最大面积 |
| 朱红 | `#D22B1E` | 斜楔形、装备主色、强调块 |
| 墨黑 | `#16130F` | 轮廓线、剪影、大色块 |
| 赭金 | `#C79131` | 金属受光面、平行线束、点睛矩形 |
| 钴蓝 | `#3E6E8C` | 点睛：海面、天空、机械阴影面，用量不超过 10% |

规则：

- 平涂无渐变，同一块面里只允许一个颜色
- 颜色靠**色块并置**产生层次，不靠明暗过渡
- 赭金只用来提亮金属和做平行线束，不要大面积铺
- **背景大面积用米白 + 墨黑，朱红在背景里以楔形/斜带出现**，避免形成"红白大面积分割"的旗子联想

## 2. 线条

- 粗黑墨线勾勒主体轮廓，笔触偏钢笔速写，允许略有抖动
- 轮廓线不是均匀描边：主体关键结构加粗，细节处收细
- 背景辅助线用**同向平行的细黑线或赭金线**（hatching），**不是**从一点发散的射线

## 3. 几何语言

- **斜切色块**：1–2 条粗大的斜带/楔形把画面切开，构成主义的核心动作
- **阶梯几何**：阶梯、梯田、层叠台阶，沿画面下缘或侧边排布
- **城市工业剪影**：烟囱、塔吊、水塔、屋顶天际线，纯黑剪影压在纸底上（苏联宣传画最经典的背景层）
- **平行斜线束**：一组同向平行的细线作节奏纹理
- **几何山形**：尖锐三角形的层叠山峦，黑/红/赭金分层（仅在题材需要自然背景时用）
- **透视网格地面**：向消失点收敛的黑红米白方格面板
- **悬浮色块**：一两块纯色矩形/方形作为视觉锚点

## 4. 印刷质感

- 胶印/丝网印网点（halftone）在色块边缘可见
- 纸纹颗粒贯穿全图
- 套色轻微错位（misregistration），红黑边界有 1–2px 的错位
- 做旧：磨损斑、划痕、边缘泛黄

**注意**：做旧不能盖过可读性。纸底过脏会让画面从"复古"变成"脏"。

## 5. 主体

- 军事装备为主：战机、坦克、军舰、直升机、火箭、雷达、防空阵地
- 主体占画面主导（通常 60% 以上），构图上偏重、大仰角或强透视
- 人物（地勤、机组）用剪影或简化色块，人数少、手势明确
- 人物**通常不画五官**，这是风格的一部分，不是缺陷

## 6. 禁止项

- **红日轮 + 放射光芒的旭日旗构图**（见开头红线专章；非旗色放射允许）
- 任何**无来源的**文字、标语、字母（原照真实标识除外，见第 6.5 节）
- 渐变、阴影、体积光、反射高光、写实纹理
- 装饰性印章、角标、出品标记
- 边框、画框
- 照片的原始水印（会被 AI"翻译"成乱码字符，必须在 prompt 里禁止）

## 6.5 标识必须保留（用户硬性要求，2026-11）

**原照上真实存在的标识，一个都不许省**——这不是"文字"，是装备身份：

| 必须保留 | 说明 |
|----------|------|
| 八一军徽（星 + 八一 + 两侧翼条） | 空军/海军航空兵机徽，低可视度样式 |
| 国旗、军旗 | 舰艇桅杆旗、机尾旗 |
| 机号 / 尾号 | 如 61821、61820，逐位复刻 |
| 舷号 | 如福建舰 18 |
| 部队番号、中队标识 | 原照有就留 |

区分标准：**原照里有的标识 = 保留；模型自己编出来的字 = 必须清掉。**

实现手段（2026-11-21 起优先级反转）：

1. **首选：prompt 里直接让模型复刻**——写明具体编号（如 `hull number 106 painted on the bow`）与机徽名称位置。参考图实测：短英文数字（106/3506/FK322）、红星机徽、鲨鱼涂鸦模型渲染可靠。
2. **兜底：Pillow 补画**——仅当标识是复杂中文（如垂尾书法字）或模型渲染糊掉时使用。生成时把标识位置留成干净纯色面，出图后按实测坐标补画（脚本模板见 `_tools/draw_bayi_insignia.py`）：
   - 抹旧痕：带颗粒的机身色 + 高斯羽化遮罩（纯色矩形会留方框）
   - 定位：裁小块放大（6–8 倍）→ 让视觉模型报比例 → 反推原图坐标
   - 写字：Windows 字体（`simhei.ttf`），颜色取机身附近实测的浅色描边值
3. 补完把该区域放大复核：字形是否完整、有没有压到轮廓线、底色有没有接缝。

## 7. 亮度校准 · 高调三色（2026-11 用户标准，仅约束背景与非写实装饰；装备主体见第 0 节）

> ⚠️ 2026-11-21 起本节降级：装备主体保留原涂装配色（第 0 节优先），本节的卡其三色规则只在用户明确要求"装备也海报化配色"时使用；用于背景时依然有效。

用户对标的是 B 站 UP 主那类**高调四色版画**，不是"泛苏联复古"。第一版交付因为偏暗被打回，具体偏差：

| 维度 | 正确（用户标准） | 错误（v1 教训） |
|------|-----------------|----------------|
| 纸底 | 亮米白 `#F2EBDC`，接近发白，占画面 60% 以上 | `#EFE5D2` 又叠重做旧，整体压灰 |
| 装备中间调 | **卡其土黄 `#C9A46B`**（车体、舰体、飞行服全靠它） | 深灰、军绿、墨绿——这是最大偏差 |
| 暗部 | 纯黑 `#14110E`，只出现在阴影面与轮廓 | 大面积黑灰压角、压天 |
| 红 | 亮朱红 `#D8342A` 大三角楔，从画面边缘插入 | 暗红小色块 |
| 印刷质感 | 几乎无，干净利落 | 满屏网点 + 颗粒 + 做旧划痕 + 暗角 |

**画法本质**：每个物体只用三档——亮米白（受光）、卡其土黄（本色）、纯黑（暗面），三档之间靠细黑线分隔。不设灰阶，所以不可能画暗。

**硬性要求**（prompt 里必须出现）：

```
High-key limited palette, only four inks: bright cream paper (#F2EBDC), pure black (#14110E),
bright vermilion red (#D8342A), warm khaki tan (#C9A46B) as the single mid-tone for all
vehicle bodies and equipment. No dark grey, no olive green, no dark brown, no muddy tones.
Crisp clean modern print: minimal grain, no vignette, no darkening at the edges.
The overall image reads light, high-key and airy with large areas of bright cream.
```

自检口径：**缩略图看整体是不是"发白/发亮"**。第一眼觉得偏暗、偏脏，就是不合格，重出。

## 8. 与参考族的区别

容易混的四种"看起来差不多但不是"：

| 错误类型 | 表现 |
|----------|------|
| 泛苏联风 | 配色更艳、加入大量渐变和写实金属反射 |
| 泛军事写实 | 追求真实质感，只有构图借了构成主义 |
| 美式复古海报 | 出现胶片褪色棕黄、圆形 badge 徽章、军衔领章 |
| **旭日旗化** | 背景出现扇形放射/日轮，无论配色多苏联都算失败 |
